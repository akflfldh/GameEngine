# GameEngine
자체게임엔진
영상 주소: https://www.youtube.com/watch?v=ToLwZjdTdFw 

1인 개발로 진행하고있는 자체엔진프로젝트입니다.\
C++,DirectX12를 기반으로 되어있습니다.\
단 현재는 크로스 플랫폼과 여러 프로그래밍패턴을 고려한 대대적인 리팩토링을 진행중입니다.




현재까지 구현된 기능으로는 DirectX12기반 렌더링파이프라인 ,맵 저장/로드 ,\
Fbx에니메이션모델 임포트, 에니메이션클립분할 UI , 에니메이션 블랜딩 상태전이그래프,\
매크로를기반으로한 리플렉션시스템, 파일 드래그앤드랍 등등입니다.

리팩토링 계획&진행 : 모듈화,크로스플랫폼을고려한 추상화, 각 모듈별 기능 확장,\ 
안전성과 신뢰성을 높이기위해 기존 직접구현부분을 서드파티 라이브러리로 대체 
간단한 매크로기반 리플렉션시스템에서 Clang/LLVM을 사용한 리플렉션시스템으로 전환
